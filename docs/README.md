# Проектная документация

Каталог предназначен для проектных документов, сопровождающих разработку
веб-приложения «Сервис трекинга заказов и инвентаря для ПВЗ».

## Состав документов

| Документ | Этап практики | Расположение |
|---|---|---|
| Назначение и область применения, User Stories, Use Cases | день 1 | `день 1/назначение и область применения .docx` |
| Техническое задание (МКП.1240910-01 90 01) | день 2 | `день 2/Техническое_задание.docx` |
| Проект структур автоматизированной системы | день 2 | `день 2/Проект_структур_АС.docx` |
| Спецификация требований | день 3 | `день 3/Спецификация_требований_Кирдун.docx` |
| Модели бизнес-процессов (BPMN, диаграмма деятельности) | день 4 | `день 4/` |
| Отчёт по базе данных и ПО, ER-диаграммы в трёх нотациях | день 5 | `день 5/Отчет_БД_и_ПО.docx` |
| Функциональные модели IDEF0 | день 6 | `день 6/Отчет.docx` |
| План разработки проекта | день 7 | `день 7/План_практики_обновленный.docx` |

## Документация в составе репозитория

| Файл | Назначение |
|---|---|
| `README.md` | назначение проекта, стек, структура, инструкция по разворачиванию |
| `CHANGELOG.md` | журнал изменений по дням практики |
| `.env.example` | образец файла настроек окружения |

## Планируемые документы

* краткая пользовательская инструкция для ролей «Клиент» и «Администратор» (25-й день);
* описание сценариев функционального тестирования;
* презентация проекта к защите (25-й день).
